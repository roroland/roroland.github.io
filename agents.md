## Agents Documentation

This project is a personal site built with [Eleventy](https://www.11ty.dev/) (11ty), using Sass for CSS preprocessing and PostCSS for post-processing. Below are the key components and build processes involved:

### Build Tools & Scripts

| Script         | Command                | Description                                              |
| -------------- | ---------------------- | -------------------------------------------------------- |
| `devserver`    | `npm run devserver`    | Eleventy dev server (`eleventy --serve`)                 |
| `watch:sass`   | `npm run watch:sass`   | Watches SCSS files and compiles to CSS                   |
| `start`        | `npm start`            | Runs devserver + watch:sass in parallel                  |
| `build:site`   | `npm run build:site`   | Generates static site via Eleventy                       |
| `build`        | `npm run build`        | Full pipeline: Sass → Concat → PostCSS → Compress → Site |
| `compile:sass` | `npm run compile:sass` | Compiles `scss/style.scss` → `css/style.comp.css`        |
| `concat:css`   | `npm run concat:css`   | Concatenates CSS files into `style.concat.css`           |
| `prefix:css`   | `npm run prefix:css`   | Autoprefixes CSS via PostCSS → `style.prefix.css`        |
| `compress:css` | `npm run compress:css` | Compresses CSS → `style.css`                             |

### CSS Build Pipeline

```
scss/style.scss
  → (Sass)
css/style.comp.css
  → (concat)
css/style.concat.css
  → (PostCSS + Autoprefixer)
css/style.prefix.css
  → (Sass compress)
css/style.css  (final output)
```

### File Structure

```
roroland.github.io/
├── _includes/content/     # Nunjucks partials (4 modules)
│   ├── layout.html        # Responsive Web Design
│   ├── css.html           # Modular CSS
│   ├── music.html         # Music composer
│   └── ui.html            # UI Design
├── scss/                   # Source SCSS files
│   ├── style.scss         # Main: imports + scroll-driven animations
│   ├── abstracts/         # Variables, mixins, functions
│   └── components/        # Reusable component styles
├── css/                   # Compiled CSS outputs
│   ├── style.css          # Final (compressed)
│   ├── style.comp.css     # Sass compilation
│   ├── style.concat.css   # Concatenated
│   └── style.prefix.css   # PostCSS autoprefixed
├── js/
│   └── script.js          # Feature modal, sub-menus, placeholder tracking
├── images/                 # Static images
├── _site/                 # Build output (generated by Eleventy)
├── eleventy.config.js     # Site configuration
├── index.html             # Main page template
└── package.json           # Project metadata & scripts
```

### Customization

To add new agents or modify existing ones, update the `package.json` scripts or Eleventy configuration in `eleventy.config.js`.

**Note**: This documentation assumes no explicit 'agent' configurations beyond the static site generation tools listed above.
